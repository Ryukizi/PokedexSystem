# Pokédex — PokeAPI

Projeto de uma Pokédex desenvolvida com **HTML, CSS e JavaScript**, utilizando a [PokeAPI](https://pokeapi.co/) para consumir e exibir informações sobre Pokémon de forma dinâmica.

A aplicação realiza requisições à API e apresenta os Pokémon em formato de lista, exibindo informações como nome, número e tipo.

### 🚀 Funcionalidades

* Consumo de dados através da **PokeAPI**.
* Listagem dinâmica de Pokémon.
* Exibição do número, nome, imagem e tipos de cada Pokémon.
* Identificação de cada Pokémon através do seu **ID**.
* Página/aba de detalhes baseada no ID do Pokémon.
* Requisições assíncronas utilizando **JavaScript**.
* Interface responsiva e estilizada com **CSS**.

### 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da aplicação.
* **CSS3** — Estilização, layout e responsividade.
* **JavaScript (ES6+)** — Lógica da aplicação, consumo da API e manipulação do DOM.
* **PokeAPI** — Fonte dos dados dos Pokémon.

### 📚 Objetivo

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento web, principalmente **consumo de APIs, requisições assíncronas, manipulação do DOM, organização de código JavaScript e criação de interfaces com HTML e CSS**.
